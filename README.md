# 🧑‍💻 Atividade Flexbox

Este repositório contém uma **atividade de layout utilizando Flexbox**, que é uma técnica moderna e poderosa para criar layouts responsivos e flexíveis com **CSS**.

## 📌 Sobre o Projeto

O objetivo deste projeto é demonstrar o uso do **Flexbox** para criar layouts responsivos e organizados. Com o Flexbox, podemos alinhar, distribuir e dimensionar os itens dentro de um contêiner de maneira eficiente, sem a necessidade de usar floats ou posicionamento absoluto.

## ⚙️ Funcionalidades

- 🎨 Layouts responsivos utilizando **Flexbox**  
- 🧩 Alinhamento e distribuição de elementos de forma eficiente  
- 📱 Design adaptável a diferentes tamanhos de tela, de desktops a dispositivos móveis  
- 💡 Boas práticas de design para garantir uma boa usabilidade

## 🛠 Tecnologias Utilizadas

- **HTML5**
- **CSS3** (Flexbox)
